## Project Overview

This is a personal academic website for Russ Poldrack built with Quarto. It includes a publication list
generated from `academicdb` data and an archive of older blog posts. GitHub Actions renders and deploys
the site to GitHub Pages on every push to `main`.

## Build and Development Commands

```bash
uv sync              # install dependencies
make preview         # live-reload local preview (uv run quarto preview)
make render          # full local render into docs/ (for checking only; not deployed)
make test            # run the pytest suite
make import-blogger  # regenerate legacy Blogger posts in blog/posts/
```

To publish, commit and push to `main`; CI does the rest.

## Architecture and Key Files

### Quarto Configuration
- `_quarto.yml`: site configuration (navbar, theme "flatly" + `styles.css`, TOC)
  - Output directory is `docs/`, which is gitignored (CI renders it fresh)
  - `render:` is limited to `*.qmd` and `blog/**/*.qmd`, so Markdown files such as this one are never published

### Content Files (`.qmd`)
- `index.qmd`: home page with bio, grid layout, rounded profile image, and profile links
- `publications.qmd`: publication list generated by an embedded Python cell
  - Reads `publications.yml` (committed; updated by the academicdb bot via PRs)
  - Formats publications by year with authors, titles, DOI links, and venues; skips ignored entries
  - Citation formatting lives in `src/poldrack_github_io/publications.py` (PubMed-style names, author
    truncation above 20, venue cleanup); the cell adds `src/` to `sys.path` since CI doesn't install the package
- `talks.qmd`: static list of YouTube videos and talk slides

### Blog (`blog/`)
- `blog/index.qmd`: listing page for `blog/posts/` (served at `/blog/`); notes that new posts are on Substack
- `blog/posts/<slug>/index.qmd`: one folder per post; native posts are written by hand
- Legacy Blogger posts are generated by `make import-blogger`, which re-fetches russpoldrack.blogspot.com
  (posts, comments, images) and overwrites those post folders
- Converter code lives in `src/poldrack_github_io/blogger_*.py`; tests in `tests/`

### Other Files
- `fix_mastodon_link.py`: adds `rel="me"` to the Mastodon navbar link in `docs/index.html`
  (required for Mastodon verification); runs in CI after `quarto render`
- `config.toml`: legacy configuration, not used for the build
- `pyproject.toml`: Python dependencies (managed with uv)

## Deployment and Automation
- `.github/workflows/render.yml`: on push to `main`, runs `quarto render .` and `fix_mastodon_link.py`,
  then deploys `docs/` to GitHub Pages (Pages source is "GitHub Actions")
- `.github/workflows/review-dispatch.yml`: when an `academicdb/review-*` PR is closed, notifies the
  `poldrack/academicdb` repo
- Publication updates arrive as commits/PRs from the academicdb bot that modify `publications.yml`
